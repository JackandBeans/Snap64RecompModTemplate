# Snap64 Recomp Mod Template

This is the page Thunderstore shows for the mod. Replace it with your own:
what the mod does, its options, and how to install it.

An example mod for [Snap64 Recomp](https://github.com/JackandBeans/Snap64Recomp),
the native PC port of Pokémon Snap. When it is on and its option is set, it
writes a line to the port's log each time the game sets up a scene.

## Installing

Mod managers do not support Snap64 Recomp. Use **Manual Download** on this
page, then drop the downloaded zip on the game window, or put the zip in the
`mods` folder beside `Snap64Recomp.exe` (Snap64 Recomp 1.1.0 or later). The
mod loads the next time the game starts. Options > Mods turns it on or off.
